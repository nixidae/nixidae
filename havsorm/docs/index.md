# havsorm

Salt states written in Nix. havsorm is a Salt extension that adds a
`#!nix` renderer, Nix pillar, and states for the Nix store and NixOS
hosts. huggorm evaluates the SLS file in the Salt process, so a minion
needs no Nix daemon and no `nix` command.
